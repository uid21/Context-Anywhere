Windows 10/11 x64 portable deployment wizard. After completely extracting the ZIP, double-click ContextAnywhere.exe.

v0.2.3 Update:
- Check recorded R2 buckets and OAuth KV before redeployment, automatically filling in missing resources.
- No longer submit invalidated KV identifiers to the Worker, nor retain success status when deployment is incomplete.
- Cloudflare error messages now distinguish between missing resources and authorization issues.

Retains step-by-step copying of MCP address, name, and authorization password, rounded corners interface, light/dark mode, small window adaptation, and Obsidian password-free import. The accompanying AI Bridge 0.4.2 is included in the package.

Deleting the program folder will preserve the knowledge base, cloud resources, and encrypted deployment records.
